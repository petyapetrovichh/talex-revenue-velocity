# REVENUE VELOCITY — отчёт по черновику (ночь 28→29 сентября)

## Что готово

**Видео:** `rv/out/rv_draft_v2_720p.mp4` (2:07, превью для телефона, 63 МБ) и `rv/out/rv_draft_v2_1080p.mp4` (1920×1080, 30 fps, 12 Мбит/с, 189 МБ). Любую версию можно пересобрать из кода одной командой (см. `rv/README.md`).

- 34 шота в 8 главах по нашей раскадровке из брифа, расширенной под тайминг трека:
  интро в дата-холле → Look 1–2 (AGI/UHI, билборды, revenue sharing) → Look 3 (три модели = три героини) → Look 4 (shipped, live-дашборд) → пре-припев (lock in) → припев → бридж (дашборд, гарантийная бирка, «there is no waiting list») → аутро (care-label, «Made with Claude», финальная карточка).
- Каждое слово лирики появляется на экране в момент, когда его произносят. Автоматическая проверка даёт 148/148.
- Движок свой, на JS/WebGL. Сделано: 2.5D-параллакс по картам глубины, текст позади героини (маска по глубине), цветной halftone без серости v1 оригинала, CV-рамки на лице, бирки-look-карточки, чат-окна трёх моделей, график buyback, чек с разделением выручки, split-flap счётчик «REVENUE SHARED · LIVE» как сквозной приём (аналог countdown у оригинала), переходы (flash, whip, glitch-slices, flap-wipe, зум через CV-рамку, CRT, бумажная шторка).

## Решения, которые я принял сам (ты спал)

1. **Кадры героини**: только готовые из `midjourney/`, без новых генераций. Это был твой выбор в опросе. Кадры, которые автор забраковал в direction-log (героиня «уехала» по этничности), не использовал.
2. **Звук временный.** Доступа к Suno из контейнера нет. Сделал подложку: инструментал оригинала (разделил на стемы), перемонтированный по тактам до 2:07, плюс наши spoken-строки, озвученные ElevenLabs (бесплатный тариф, потрачено ~600 символов). Оригинальный вокал оставил только на «(It's so over?) WE'RE SO BACK!», там слова совпадают с нашими. **Строки припева 1–4 пока без голоса**, только текст на экране.
   Эта подложка — чужая композиция и нужна только для тайминга. **Публиковать с ней нельзя.**
3. **Цифры — плейсхолдеры.** Счётчик revenue, доли 40/35/25, buyback-столбики, uptime 212 дней, «18,204 в waiting list», чек RoamFi eSIM $12 я придумал для визуала. Всё собрано в одном файле, `rv/engine/data/facts.json`: подставь реальные значения и перерендерим.
4. **Строка про Маска.** В лирике «Musk said it: own nothing, still get paid». Дословно он так не говорил: он говорил про «universal high income», а «own nothing» — это мем WEF. На билборде подписал нейтрально, «AS SEEN ON YOUR TIMELINE», без кавычек-цитаты. Стоит решить, оставляем ли строку.
5. Шрифты: Barlow Condensed, Inter, IBM Plex Mono (все OFL). Логотипов ChatGPT/Gemini/Claude нет, только названия текстом.

## Что нужно от тебя

1. Посмотреть превью и дать заметки по вкусу: темп монтажа, плотность графики, какие шоты заменить.
2. **Утвердить лирику** и сгенерить трек в Suno. Все поля готовы к вставке в `rv/SUNO.md`. Положи выбранный дубль в репо (или скинь файл), дальше:
   `python3 rv/tools/align.py rv/work/suno.wav` → слова выравниваются по вокалу, все шоты перетаймятся сами → рендер.
3. Дать реальные цифры для `facts.json`.
4. По желанию: 1–2 новых кадра под сцены, которых в архиве нет (например, героиня с UI RoamFi). Промпты напишу под канон персонажа.
